# macOS
version: 15 Sequoia

- [x] `Cmd+Space` Spotlight — search apps, files and the web
  tags: #essential
- [ ] `Shift+Cmd+4` Screenshot of an area — saved to the desktop
  tags: #screenshot
  Add Ctrl to copy it to the clipboard
  instead of saving a file.
- [ ] `Ctrl+Cmd+Q` Lock the screen

## VS Code
version: 1.95

- [x] `Shift+Cmd+P` / `F1` Command Palette — run any command
  tags: #essential
- [ ] `Cmd+K Cmd+S` Keyboard Shortcuts editor
  version: 1.90+

### Editing

- [x] `Cmd+D` Add next match to the selection
  tags: #multi-cursor
- [ ] `Shift+Cmd+L` Select all matches
  tags: #multi-cursor
- [ ] `Alt+Up` / `Alt+Down` Move line up / down

## Finder

- [ ] `Shift+Cmd+.` Show hidden files
- [ ] `Cmd+Backspace` Move to Trash
